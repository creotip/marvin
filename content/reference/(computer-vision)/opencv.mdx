**OpenCV** (Open Source Computer Vision Library) is a widely used
open-source library of classical computer-vision algorithms — image
filtering, edge detection, feature matching, camera calibration — written
in C++ with bindings for Python and other languages. It predates the deep
learning era and is distinct from a [CNN](/reference/cnn): OpenCV's
classical algorithms are hand-engineered, not learned, though it's
commonly used alongside deep learning models for preprocessing images
(resizing, color conversion) or running inference.
