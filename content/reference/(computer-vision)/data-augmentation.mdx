---
title: Data Augmentation
description: Data augmentation expands a training set by applying label-preserving transformations (crops, flips, color jitter) to existing examples, fighting overfitting for free.
---

**Data augmentation** artificially expands a training set by applying
label-preserving transformations to existing examples — random crops,
flips, rotations, or color jitter for images. A photo of a cat flipped
horizontally is still obviously a cat, so this manufactures new, valid
training examples at no extra labeling cost, and is standard practice in
nearly every [CNN](/reference/cnn) training pipeline as a cheap defense
against [overfitting](/reference/overfitting).
