**PyTorch** is the dominant [deep learning](/reference/deep-learning)
framework today, in both research and most production model training. It
defines computation "eagerly" (operations run immediately, like normal
Python), which makes debugging and experimentation fast, and provides
**autograd** — automatic computation of gradients via
[backpropagation](/reference/backpropagation) — so training code rarely
requires hand-deriving gradients. It's the default starting point
recommended for most model development work today.
