**CUDA** is NVIDIA's programming platform that lets frameworks like
[PyTorch](/reference/pytorch) dispatch computation to NVIDIA
[GPUs](/reference/gpu). Deep learning frameworks expose a high-level
Python API while their actual matrix-multiplication and attention
kernels run as compiled CUDA code underneath. **cuDNN** provides
optimized implementations of common deep learning operations on top of
CUDA. NVIDIA GPUs plus CUDA form the dominant hardware/software
combination for both training and serving models.
