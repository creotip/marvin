This is a from-scratch course on how AI actually works, structured like a
docs site rather than a textbook. Each lesson builds on the last:

1. [History & Landscape](/docs/history-and-landscape) — how the field got here
2. [ML Fundamentals](/docs/ml-fundamentals) — learning as optimization
3. [Neural Networks & Backprop](/docs/neural-networks-and-backprop) — the algorithm behind training
4. [Computer Vision](/docs/computer-vision) — convolutions and CNNs
5. [Attention & Transformers](/docs/attention-and-transformers) — the architecture behind modern AI
6. [LLMs](/docs/llms) — tokenization, pretraining, fine-tuning, RLHF
7. [Inference & Serving](/docs/inference-and-serving) — what happens when you hit "send"
8. [Applied & Agentic Systems](/docs/applied-and-agentic-systems) — RAG, tool use, agents

## Who this is for

You should be comfortable with basic programming and high-school math
(functions, vectors, derivatives at an intuitive level). No prior ML
background is assumed — each lesson introduces its own vocabulary before
using it.

## How to read it

Lessons are meant to be read in order — later ones assume the vocabulary
and intuition built in earlier ones. Interactive widgets for each lesson
(gradient descent playground, attention visualizer, etc.) are coming in a
later update; for now, focus on building the mental models in writing.
